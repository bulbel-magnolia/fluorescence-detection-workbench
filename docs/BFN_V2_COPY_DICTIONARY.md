# BFN V2 界面文案词典

> 状态：P0 文案已写入中英文资源并接入现有 BFN 工作流；其余页面文案随对应重构阶段实施。
>
> 目标：统一科研对象、动作、状态和科学边界的表达，并以本词典作为后续页面重构的文案合同。

## 1. 文案总则

1. 中文是中文界面的主要显示语言；英文只用于首次解释、代码标识、方程或高级信息。
2. 按钮必须同时说明动作和对象。
3. 成功反馈说明完成了什么、对象是谁、必要时包含版本或数量。
4. 错误反馈遵循“发生了什么 + 原因 + 下一步动作”。
5. 空状态遵循“当前没有什么 + 为什么需要 + 明确动作”。
6. 科学警告靠近对应结果，不只放在 tooltip。
7. “ANN 已拒绝”是有效科学结论，不是系统失败。
8. 缺失数据写“未知”“暂无测量数据”或“仅有机制预测”，不得写成 0、100% 或低风险。
9. 演示内容始终显示“演示数据 · 未经实验验证”或同等明确标识。
10. 一条文案只承担一个任务，不用营销式或拟人化表达。

## 3. 不得混用的概念

| 概念 A              | 概念 B             | 规则                                            |
| ------------------- | ------------------ | ----------------------------------------------- |
| 功能模块            | 生物元件           | 启动子/RBS/CDS 属于生物实现，不默认成为网络模块 |
| 连接                | 响应模型           | 连接只传播，变化由功能模块完成                  |
| 基础输出            | 有效截距           | 前者是响应模型参数，后者只属于 ANN 近似         |
| 响应阈值            | 有效截距           | 不得互换                                        |
| 功能参数 \(\theta\) | 生物设计变量 \(q\) | 反向设计分阶段展示                              |
| 计算预测            | 实验结果           | 候选和仿真不能写成实验已验证                    |
| 适用域              | 分析工作域         | 前者来自模型证据，后者由本次分析设置            |
| ANN 已拒绝          | 运行失败           | 前者是科学结论，后者是系统状态                  |

## 5. 按钮四级体系

### 5.1 Primary

每个页面或独立任务区域原则上一个主按钮。主按钮触发当前对象最重要的状态转换。

| 页面/任务          | 主按钮         |
| ------------------ | -------------- |
| 项目无数据         | 导入实验数据   |
| 数据导入末步       | 注册实验数据集 |
| 模块新建/编辑      | 保存功能模块   |
| 网络编辑器（静态） | 运行静态仿真   |
| 网络编辑器（动态） | 运行动态仿真   |
| 静态工作域         | 计算工作域响应 |
| 反向设计           | 生成候选设计   |
| 版本编辑           | 保存模型版本   |

### 5.2 Secondary

- 验证网络
- 保存草稿
- 预览响应
- 比较模型
- 导出结果
- 生成 ANN 近似
- 复制功能模块
- 查看数据校验

### 5.3 Tertiary

- 查看详情
- 查看历史版本
- 下载原始数据
- 查看运行日志
- 查看证据来源
- 恢复旧版本
- 导入 BFN-IR
- 导出 BFN-IR

### 5.4 Destructive

- 删除功能模块
- 删除网络
- 删除实验数据集
- 放弃未保存更改
- 清除仿真结果
- 重置演示项目

确认按钮不得写“是/否/确定”。使用明确对象：

| 场景         | 确认           | 取消/保留    |
| ------------ | -------------- | ------------ |
| 删除模块     | 删除功能模块   | 保留功能模块 |
| 删除网络     | 删除网络       | 保留网络     |
| 放弃编辑     | 放弃未保存更改 | 继续编辑     |
| 重置演示项目 | 重置演示项目   | 保留当前项目 |

确认说明模板：

> 将删除/覆盖什么 + 会影响哪些引用对象 + 是否可恢复。

示例：

> 重置演示项目会覆盖当前本地 BFN 项目和本地运行记录。此操作无法撤销。导出的 BFN-IR 文件不会被删除。

| ---------- | ------------------------ | ---------------------------------------------------- | ---------------------- |
| 无输入源   | 当前网络还没有输入源     | 添加输入源后，可以设置固定值、工作范围或动态信号。   | 添加输入源             |

## 11. 错误反馈

### 11.1 模板

> [发生了什么]。[具体原因]。[下一步操作]。

### 11.2 示例

**端口量类型不匹配**

> 连接失败。上游端口输出 AHL 产生速率（nM/h），下游端口要求 AHL 浓度（nM）。请在两个功能模块之间插入积累模块。

**端口实体不匹配**

> 连接失败。上游端口输出 3OC6-HSL，下游端口要求 3OC12-HSL。请选择实体一致的端口，或插入具有明确转换模型的功能模块。

**单位可换算**

> 连接可建立。平台会将上游的 μM 自动换算为下游要求的 nM；连接仍执行恒等传播。

**数据行解析失败**

> 第 4 列“AHL”中有 3 个值无法解析为 nM：第 18、21、36 行。请修正这些值后重新校验。

**模型适用域外**

> 当前输入超出响应模型 v2.3 的适用域（5–20 nM）。本次结果包含外推；请调整输入范围或选择适用域覆盖该范围的模型版本。

**导入 schema 不兼容**

> 无法导入该 BFN-IR 文件。文件版本为 {fileVersion}，当前应用支持 {supportedVersion}。当前本地项目未被修改。

**动态求解失败**

> 动态仿真未完成。求解器在 {time unit} 处无法继续收敛。请检查初始状态和输入范围，或在高级设置中减小时间步长。

避免：

- 连接失败，请检查输入。
- 参数错误。
- 文件格式错误。
- 未知错误。

## 12. 科学边界与警告

| 场景         | 推荐文案                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------- |
| 演示         | 演示数据 · 未经实验验证                                                                  |
| 外推         | 当前结果包含外推。超出适用域的区域已在图中标出。                                         |
| 模型上下文   | 当前响应模型仅在 {host}、{medium}、{temperature} 条件下表征。                            |
| 多输入假设   | 默认独立，输入间交互关系未验证。                                                         |
| ANN accepted | 当前分析工作域内，仿射模型能够可靠概括完整响应。                                         |
| ANN rejected | 当前分析工作域内存在明显非线性，ANN 近似误差超过设定标准。后续仿真继续使用完整响应模型。 |
| 候选未构建   | 当前候选设计为计算预测，尚未经过实验构建。                                               |
| 仅机制预测   | 该指标仅有机制预测，暂无测量数据。                                                       |
| 证据不足     | 当前证据只支持所列上下文和适用域，不应外推为通用生物结论。                               |

这些文案必须紧邻结果、候选或模型摘要，不得只放 tooltip。

## 13. 端口 P=(E,Q,U) 文案

端口属性按三行显示：

```text
实体        3OC6-HSL
量类型      浓度
单位        nM
```

连接校验显示：

```text
实体匹配        匹配
量类型匹配      匹配
单位状态        可直接使用 / 自动换算 μM → nM / 不兼容
传播规则        恒等传播 uⱼ = yᵢ
```

IdealEdge 页面禁止出现：

- 权重
- 偏置
- 增益
- 延迟
- 衰减
- 噪声
- 状态
- 自定义变换

## 17. 禁止和慎用文案

禁止用于主要流程：

- 智能分析
- 一键优化
- 一键生成
- AI 推荐
- 立即体验
- 探索更多
- 科技指数
- 智能权重
- 神经网络训练（用于 ANN 近似时）
- 已证明输入彼此独立
- 低风险（无数据时）

慎用且必须加对象：

- 保存 → 保存功能模块 / 保存网络版本
- 删除 → 删除实验数据集 / 删除连接
- 导出 → 导出仿真结果 / 导出 BFN-IR
- 运行 → 运行静态仿真 / 运行动态仿真
- 完成 → 工作域响应已计算，共 100 个采样点
