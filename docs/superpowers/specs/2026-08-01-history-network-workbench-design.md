# 检测记录与网络设计工作台升级设计

**日期：** 2026-08-01
**状态：** 讨论内容已确认，待文档复核
**适用端：** Windows 荧光检测工作台

## 1. 设计目标

本次升级聚焦两个核心工作区：检测记录和生物网络设计。目标是在不改变荧光检测数据主干的前提下，提高历史记录的信息密度、科学表达和可读性，并把网络连接从表单式操作升级为直接画布交互。

具体目标如下：

1. 检测记录以曲线为核心呈现完整数据，而非只显示少量摘要值。
2. 严格区分分析记录与 HC-08D 实测原始记录，不生成设备没有提供的数据。
3. 网络工具栏形成清楚的两级命令结构，节点添加操作更加醒目。
4. 用户可以直接从节点端口拖出连线，无需进入独立接线模式。
5. 全面提高暗色界面文字对比度、字号和中英文布局稳定性。
6. 保留 bionet-studio 视觉家族的精密科研工作台质感和克制动效。

## 2. 范围与边界

### 2.1 本次包含

- 检测记录列表与详情布局重构
- 历史曲线、指标、元数据和导出入口
- 分析记录与真实设备记录的差异化展示
- 网络工具栏分组和按钮层级优化
- 节点端口、拖拽连线、边权重编辑和连接校验
- 撤销与重做集成
- 中文与英文文字布局、字号、对比度和动效优化
- 相关自动化测试与桌面端构建验证

### 2.2 本次不包含

- 更改 HC-08D 通信协议
- 将 CLR 通道自动定义为背景值
- 为真实设备记录生成背景、校正信号、浓度或实验结论
- 引入新的校准系数、质量阈值或生物学参数
- 改变已有检测记录的原始持久化内容
- 修改网络计算模型的科学含义

## 3. 检测记录页面

### 3.1 页面结构

页面采用“左侧紧凑记录列表 + 右侧宽幅详情”的主从布局。

左侧列表负责检索和快速切换记录。右侧详情以曲线图为视觉中心，展示当前记录的核心指标、通道数据、来源信息和可执行操作。该结构替代当前大面积空白列表与狭窄详情栏的布局。

建议桌面宽屏比例为：

- 左侧列表：约 30% 至 34%
- 右侧详情：约 66% 至 70%
- 最小可用宽度下，列表保持固定可读宽度，详情区域优先获得剩余空间

### 3.2 记录列表信息

每条记录展示：

- 样本编号
- 检测或导入时间
- 数据来源：HC-08D、演示、文件导入等
- 记录状态：原始记录、已分析、数据不完整等
- 通道峰值或结果摘要

列表文字默认单行显示。超长样本编号采用省略号，并通过悬停提示查看完整内容。状态信息通过文字、图标和颜色共同表达，不依赖颜色单独传达。

### 3.3 详情信息层级

右侧详情由四层组成：

1. **记录标题与状态**：样本编号、来源、时间、分析状态。
2. **核心指标**：采集时长、数据点数、峰值、终值、记录类型和校正状态。
3. **曲线工作区**：通道切换、信号类型切换、曲线图和悬停读数。
4. **补充信息与操作**：检测参数、算法版本、协议版本、关联网络设计、导出操作。

技术版本和较长元数据放入可展开详情，避免与曲线争夺首屏空间。

### 3.4 曲线展示规则

#### 分析记录

分析记录从已经保存的通道曲线读取数据。默认展示各通道的校正信号，并支持：

- 原始信号、背景值、校正信号切换
- 单独显示或隐藏每个通道
- 悬停查看时间点、通道名、信号类型和精确数值
- 图例与曲线颜色保持一致

当前校正关系为：

```text
校正信号 = max(0, 原始信号 - 背景值)
```

该值仍使用相对荧光单位，不自动解释为浓度。

#### HC-08D 实测原始记录

HC-08D 当前实际提供 `480 nm`、`515 nm`、`555 nm` 和 `CLR` 四路原始数据。详情页只展示这些真实通道的原始曲线，并显示“未配置背景校正”。

CLR 不自动视为背景通道。只有在硬件协议和实验方案明确其含义后，才能将其纳入背景校正模型。

#### 数据完整性原则

- 页面不为缺失信号补零或生成模拟曲线。
- 缺失曲线时显示现有数据和缺失原因。
- 演示数据保持清晰的演示标识。
- 旧版本记录按其实际保存字段展示。

### 3.5 大数据量处理

数据点较多时，绘图层可进行仅用于屏幕显示的降采样。以下操作继续使用完整数据：

- 统计值计算
- 悬停精确读数
- 文件导出
- 后续分析输入

显示降采样不得覆盖原始记录。

### 3.6 空状态

没有历史记录时，页面保留简洁说明并提供两个主要入口：

- 载入演示记录
- 导入检测文件

空状态不展示虚构指标或占位曲线。

## 4. 网络设计工作台

### 4.1 工具栏结构

顶部工具栏改为两排分组命令区。

第一排为项目与历史操作：

- 网络模板
- 撤销
- 重做
- 导入模型
- 导出模型
- 重置模板

第二排为节点创建操作：

- 添加传感节点
- 添加处理节点
- 添加响应节点
- 添加记忆节点
- 添加输出节点

节点按钮使用同一视觉体系下的差异化语义色，并提供足够宽度。原有“连接节点”按钮和“接线模式”入口删除。

### 4.2 响应式规则

- 按钮文字使用完整单行标签。
- 工具组不可在中文字符之间任意断行。
- 窗口宽度不足时，优先按组重排；仍不足时允许命令区横向滚动。
- 不通过降低关键按钮字号解决溢出。
- 中英文切换后使用内容宽度重新布局。

## 5. 画布直接连线

### 5.1 基础交互

- 拖动节点主体：移动节点。
- 从输出端口按下并拖动：开始创建连接。
- 拖到有效输入端口：目标端口高亮并产生轻微吸附反馈。
- 松开鼠标：校验通过后创建连接。
- 在空白处松开或目标无效：取消预览，不修改模型。

整个过程始终处于正常画布状态，不要求用户切换接线模式。

### 5.2 端口规则

| 节点类型 | 输入端口 | 输出端口 |
| --- | --- | --- |
| 传感节点 | 无 | 有 |
| 处理节点 | 有 | 有 |
| 响应节点 | 有 | 有 |
| 记忆节点 | 有 | 有 |
| 输出节点 | 有 | 无 |

端口平时以低亮度保持可见，悬停、拖线和成为有效目标时提高亮度。端口必须具有足够的可点击区域，视觉圆点与实际命中区域可以不同尺寸。

### 5.3 连接预览与创建

拖线期间显示从源端口到指针位置的临时曲线。预览属于界面瞬时状态，不写入网络模型。

连接创建时执行统一校验：

- 源节点和目标节点存在
- 源节点具有输出端口
- 目标节点具有输入端口
- 不是自连接
- 不与已有同向连接重复

校验通过后，连接以默认权重 `1.00` 创建，并自动成为当前选中对象。

### 5.4 权重与连线编辑

选中连线后，右侧检查器展示：

- 来源节点
- 目标节点
- 权重
- 启用状态
- 删除操作

用户可以在检查器修改权重，也可以双击连线权重标签进行就地编辑。

- 正权重表示促进关系。
- 负权重表示抑制关系。
- 两类连接通过颜色、线型或箭头样式共同区分。
- 修改后立即进入模型状态和撤销历史。

### 5.5 删除与恢复

节点和连线支持通过检查器按钮或键盘删除。删除操作进入统一撤销与重做历史，因此不弹出阻断式确认框。删除节点时，与该节点相关的连线作为同一次历史操作移除和恢复。

## 6. 状态与数据流

### 6.1 历史记录

```text
历史记录存储
  → 记录类型判断
  → 曲线适配与统计摘要
  → 检测记录详情
```

曲线适配只负责把不同记录类型转换为可视化序列，不修改记录内容，也不引入新的科学计算。

### 6.2 网络连接

```text
端口按下
  → 本地拖线预览
  → 目标端口命中
  → 统一连接校验
  → 创建模型连接
  → 写入撤销历史
  → 选中新连线
```

画布组件负责指针交互和视觉反馈。模型层继续负责连接合法性、结构变更和可撤销状态。连接校验不在多个界面组件中重复实现。

## 7. 可读性与视觉规范

### 7.1 字号与对比度

- 正文最小字号：14 px
- 辅助说明最小字号：13 px
- 关键数据、状态和按钮使用更高字号与字重
- 暗色背景上的正文使用高对比浅色
- 重要辅助信息不得依赖过低透明度

### 7.2 换行规则

- 页面标题、按钮、短标签和状态优先保持单行。
- 较长说明按短句和语义边界换行。
- 禁止单个汉字或极短词组孤立到下一行。
- 超长标识符采用省略号与悬停全文提示。

### 7.3 动效

保留以下高级化动效：

- 端口悬停发光
- 拖线跟随与有效目标吸附
- 选中连线的轻微能量流动
- 记录切换和检查器内容的平滑过渡
- 主操作的短促状态反馈

动效以信息反馈为目的，时长保持克制。系统启用“减少动态效果”时，流动、位移和持续脉冲自动降级为静态高亮或短暂透明度变化。

## 8. 面向公众的错误表达

界面提示说明用户能理解的原因和下一步动作，不暴露内部函数名或工程状态码。

示例：

- “传感节点不能接收输入，请连接到它右侧的输出端口。”
- “这两个节点已经连接，无需重复添加。”
- “该记录只包含设备原始信号，尚未配置背景校正。”
- “曲线数据不完整，当前仅显示可读取的通道。”

技术细节继续保留在开发日志中。

## 10. 验收标准

完成后的第一版应满足：

1. 选中任意有效历史记录即可查看实际保存的曲线和核心指标。
2. HC-08D 原始记录不会出现虚构背景值或校正曲线。
3. 网络工具栏不再出现逐字换行，节点添加操作明显可见。
4. 用户无需切换模式即可从端口拖拽创建连接。
5. 节点类型端口规则、自连接和重复连接均得到正确校验。
6. 新连接默认权重为 `1.00`，可通过检查器和连线标签修改。
7. 正负权重具有清楚且不只依赖颜色的视觉差异。
8. 网络结构编辑完整支持撤销与重做。
9. 主要文字在暗色背景上具有稳定可读性，中英文切换不产生突兀断行。
10. 动效增强操作反馈，并支持减少动态效果设置。
