# BFN V2 页面地图与信息架构

> 状态：阶段一设计基线，尚未实施路由或持久化改造。
>
> 说明：本文中的“页面 ID”用于定义信息架构，不代表仓库当前已存在 URL Router。

## 1. 信息架构原则

BFN 工作流按科研对象和任务组织：

1. 导入实验数据
2. 建立功能模块
3. 组合网络
4. 定义输入
5. 运行完整模型
6. 理解结果边界
7. 开展反向设计

每个主要页面固定回答：

- 当前核心对象是什么。
- 对象处于什么状态。
- 当前页面要完成什么任务。
- 下一步最合理的动作是什么。
- 结果受到哪些适用域、上下文、假设或证据限制。

## 2. 当前实际页面地图

```text
AppShell（荧光检测工作台）
├─ overview      概览
├─ detection     采集
├─ modeling      网络设计
│  └─ BfnPlatformPage（单一长页面）
│     ├─ network   01 网络组合
│     ├─ analysis  02 完整模型分析
│     ├─ inverse   03 反向设计
│     └─ evidence  04 模块与证据库
├─ import        导入分析
├─ history       记录
├─ settings      设置
└─ team          团队（仅云配置可用时出现）
```

### 2.1 当前导航机制

- 顶级 section 由 Zustand 切换，不写入 URL。
- BFN 四个视图由 \`BfnPlatformPage\` 的本地 tab 状态切换。
- 当前只有一个 localStorage BFN 项目，没有项目列表和网络列表。
- 检测记录使用 SQLite/Supabase 路径；该能力不能自动解释为 BFN 数据集持久化。

## 3. 推荐的近期页面地图

推荐采用“同一桌面应用中的独立 BFN 工作区壳”。该方案保留现有荧光采集能力，同时让建模任务拥有独立项目上下文和对象导航。

```text
Desktop App
├─ 荧光检测工作区（保留现有能力）
│  ├─ 概览
│  ├─ 采集
│  ├─ 导入分析
│  └─ 检测记录
└─ BFN 建模工作区
   ├─ 项目概览
   ├─ 实验数据
   │  ├─ 数据集列表
   │  ├─ 导入实验数据
   │  └─ 数据集详情
   ├─ 功能模块
   │  ├─ 模块列表
   │  ├─ 新建/编辑模块
   │  └─ 模块详情
   │     ├─ 概览
   │     ├─ 响应模型
   │     ├─ 实验数据
   │     ├─ 生物实现
   │     └─ 版本与证据
   ├─ 网络设计
   │  ├─ 网络入口/列表
   │  └─ 网络编辑器
   │     ├─ 顶部任务栏
   │     ├─ 左侧模块库
   │     ├─ 中央画布
   │     ├─ 右侧检查器
   │     └─ 底部验证/结果/日志面板
   ├─ 仿真与分析
   │  ├─ 静态单点
   │  ├─ 静态工作域
   │  ├─ 动态仿真
   │  └─ ANN 近似
   └─ 反向设计
      ├─ 目标功能 θ*
      ├─ 生物设计空间 q
      └─ 候选设计
```

设置、导入/导出、帮助和运行日志降低一级，放入工作区菜单或具体对象的更多操作。

## 5. 页面合同

### 5.1 BFN 项目概览

| 项目     | 设计                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 核心对象 | 当前 BFN 项目                                                                 |
| 状态     | 本地/演示、保存状态、schema 版本、未解决问题                                  |
| 主要任务 | 判断项目当前完成度和下一步                                                    |
| 主动作   | 根据项目状态动态选择：导入实验数据 / 新建功能模块 / 打开网络编辑器 / 运行仿真 |
| 次要动作 | 查看最近运行、导出项目、项目设置                                              |
| 边界     | 演示数据、未验证模型、未持久化能力明确说明                                    |
| 内容     | 数据集数、模块数、网络数、阻断问题、外推运行、待验证候选、最近活动            |

### 5.2 实验数据集列表

| 项目     | 设计                                                         |
| -------- | ------------------------------------------------------------ |
| 核心对象 | 注册后的实验数据集                                           |
| 状态     | 草稿、已校验、校验失败、已弃用                               |
| 主要任务 | 查找可用于模型拟合/验证的数据                                |
| 主动作   | 导入实验数据                                                 |
| 次要动作 | 筛选、比较、查看引用                                         |
| 边界     | fixture 必须显示“演示数据 · 未经实验验证”                    |
| 列       | 名称、类型、输入、输出、条件数、上下文、校准、来源、最近修改 |

### 5.3 实验数据导入

七步向导：

1. 选择文件。
2. 识别列。
3. 指定输入、输出和单位。
4. 指定重复与对照。
5. 指定实验上下文。
6. 预览和校验。
7. 注册数据集。

每步只有一个主动作。错误必须定位到行、列和值。注册之前不把文件称为“实验数据集”。

### 5.4 实验数据集详情

同级视图：

- 数据概览
- 原始数据
- 校准过程
- 实验上下文
- 使用该数据的模型
- 版本与来源

若当前没有 BFN 数据 repository，只允许以只读 fixture 演示上述结构。

### 5.5 功能模块列表

| 项目     | 设计                                                                 |
| -------- | -------------------------------------------------------------------- |
| 核心对象 | \`FunctionalModule\`                                                 |
| 状态     | 草稿、已拟合、已验证、验证失败、已弃用                               |
| 主要任务 | 选择、创建或比较完整功能模块                                         |
| 主动作   | 新建功能模块                                                         |
| 次要动作 | 导入模块、筛选、比较模块                                             |
| 列/卡片  | 名称、输入/输出端口、静态/动态、模型状态、适用域、证据、上下文、版本 |
| 禁止内容 | ANN 权重、连接权重、虚构生物实现                                     |

### 5.6 功能模块详情

面包屑示例：

```text
项目 / 功能模块 / AHL 传感器 / 响应模型
```

同级标签：

1. 概览
2. 响应模型
3. 实验数据
4. 生物实现
5. 版本与证据

“概览”以完整响应、端口、版本、上下文、适用域和证据为核心。ANN 近似只在分析结果中出现。

### 5.7 网络入口/列表

近期若只支持单网络，页面仍需先呈现：

- 网络名称
- 当前版本
- 保存状态
- 静态/动态模式
- 模块与连接数量
- 验证状态
- 最近仿真
- 打开网络编辑器

多网络创建、复制、归档和删除在 repository 获批后再开放，不制造空壳按钮。

### 5.8 网络编辑器

#### 顶部任务栏

- 网络名称
- 当前版本
- 保存状态
- 静态/动态互斥控件
- 次要动作“验证网络”
- 主动作“运行静态仿真”或“运行动态仿真”
- 更多菜单：导入、导出、版本历史、危险操作

#### 左侧模块库

- 输入源
- 功能模块
- 输出监视器
- 显式转换模块
- Legacy 兼容模块（存在时）
- 搜索和实体/量类型/模式/证据筛选

#### 中央画布

- 模块、端口、方向和验证状态。
- 连接只显示恒等传播。
- 连接线上不得出现 weight、bias、gain、delay、noise 或自定义变换。

#### 右侧检查器

- \`InputSource\`：P=(E,Q,U)、模式、输入方式和适用域。
- \`FunctionalModule\`：端口、完整响应模型、版本、上下文、适用域、实现和证据。
- \`IdealEdge\`：来源/目标模块和端口、实体匹配、量类型匹配、单位换算。
- \`OutputMonitor\`：监视对象、单位和当前结果。

#### 底部面板

- 网络验证问题
- 仿真结果
- 运行日志
- 外推警告
- 证据警告

问题行支持定位到画布对象。

### 5.9 静态单点

| 项目     | 设计                                                            |
| -------- | --------------------------------------------------------------- |
| 核心对象 | 完整模型在一个输入点的输出                                      |
| 主动作   | 运行静态仿真                                                    |
| 结果     | 每个模块输入/输出、网络输出、参数不确定性区间、适用域、外推状态 |
| 禁止     | 默认权重、偏置、局部敏感性、对数弹性、ANN 近似                  |

### 5.10 静态工作域

| 项目     | 设计                                                |
| -------- | --------------------------------------------------- |
| 核心对象 | 分析工作域内的完整响应                              |
| 主动作   | 计算工作域响应                                      |
| 次要动作 | 生成 ANN 近似                                       |
| 结果     | 完整响应曲线/响应面、预测区间、适用域覆盖、外推区域 |
| 输入     | 最小/最大值、单位、线性/对数采样、点数              |

### 5.11 动态仿真

| 项目     | 设计                                                       |
| -------- | ---------------------------------------------------------- |
| 核心对象 | 完整时间响应 y(t)                                          |
| 主动作   | 运行动态仿真                                               |
| 输入     | 恒定、阶跃、脉冲、周期、自定义时间序列                     |
| 结果     | 输入曲线、输出曲线、内部状态、初始状态、求解状态、不确定性 |
| 次级指标 | 稳态、上升时间、峰值时间、超调、DC gain、频率响应          |

### 5.12 ANN 近似

ANN 是静态工作域的派生分析，不是功能模块属性。

显示：

- 来源模块/网络和来源版本
- 分析工作域
- 输入分布与采样方式
- 有效权重 \(W_\Omega\)
- 有效截距 \(\mathbf b_{\mathrm{eff}}\)
- R²、NRMSE、最大误差
- 已接受/已拒绝/已过期
- 完整模型与近似模型对比
- “不写回模块、不写入连接、不替代完整模型”的边界说明

### 5.13 反向设计

三阶段：

1. **定义目标功能**：得到 \(\theta^*\)。
2. **设置生物设计空间与评价偏好**：限定 \(\mathbf q\)。
3. **比较候选设计**：展示预测完整响应、各评价维度、证据、数据缺口和验证实验。

主动作统一为“生成候选设计”。综合分数只用于排序，不隐藏各维度。缺失值显示“未知”。

## 6. 状态页面地图

| 对象 | 状态         | 页面表现               | 可用动作           |
| ---- | ------------ | ---------------------- | ------------------ |
| 模型 | 草稿         | 中性状态 + 未完成字段  | 继续编辑           |
| 模型 | 已拟合       | 信息状态 + 拟合版本    | 查看拟合           |
| 模型 | 已验证       | 成功状态 + 证据范围    | 查看证据           |
| 模型 | 验证失败     | 错误状态 + 阻断问题    | 修复问题           |
| 网络 | 未验证       | 中性状态               | 验证网络           |
| 网络 | 验证通过     | 成功状态 + 时间/版本   | 运行仿真           |
| 网络 | 存在警告     | 警告状态 + 可定位问题  | 查看警告           |
| 网络 | 存在阻断错误 | 错误状态 + 可定位问题  | 修复网络           |
| 仿真 | 等待运行     | 有解释的空状态         | 运行对应仿真       |
| 仿真 | 正在运行     | 任务、进度、已完成数量 | 取消仿真（支持时） |
| 仿真 | 已完成       | 结果摘要 + 边界        | 导出/派生分析      |
| 仿真 | 已取消       | 保留配置               | 重新运行           |
| 仿真 | 运行失败     | 原因 + 修复动作        | 修改配置/重试      |
| ANN  | 未生成       | 说明生成条件           | 生成 ANN 近似      |
| ANN  | 已接受       | 科学结论，不用“成功”   | 查看对比           |
| ANN  | 已拒绝       | 警告结论，不用“失败”   | 继续使用完整模型   |
| ANN  | 已过期       | 来源版本已变化         | 重新生成           |
| 候选 | 计算预测     | 明确“未构建”           | 查看数据缺口       |
| 候选 | 待验证       | 评价与实验建议         | 记录验证计划       |
| 候选 | 已实验构建   | 构建证据               | 关联实验数据       |

## 8. 数据与能力边界

| 页面能力          | 当前数据来源       | 近期可做                | 需要额外批准                         |
| ----------------- | ------------------ | ----------------------- | ------------------------------------ |
| BFN 项目概览      | localStorage 项目  | 读取并汇总当前演示项目  | 多项目/归档/协作                     |
| 实验数据列表      | fixture 数据集     | 只读并清楚标演示        | BFN 数据集 repository 与 SQLite 迁移 |
| 功能模块列表/详情 | fixture / registry | 只读详情与筛选          | 创建、编辑、版本化、引用完整性       |
| 网络编辑器        | localStorage 项目  | 重组 UI，保留现有计算   | 多网络与协作保存                     |
| 仿真/ANN          | 当前纯函数         | 重组配置和结果          | 异步 worker、取消、远程求解          |
| 反向设计          | 演示校准映射       | 重组流程和 unknown 展示 | 真实设计库、真实证据、科学类型扩展   |

## 9. 待确认决策

1. BFN 工作区壳还是顶级产品模式。
2. 单本地项目还是多项目/多网络。
3. 是否新增 BFN 实验数据与模块的持久化 schema。
4. 模块详情先只读还是同期开放版本化编辑。
5. 是否批准候选评价字段支持未知值。
6. 960px 是否继续作为完整网络编辑器的支持宽度。

在这些决策完成前，PR 2 可先实施术语、按钮、状态与基础组件；PR 3 之后的页面结构按确认结果推进。
