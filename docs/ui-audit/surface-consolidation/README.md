## 语义检查

- `DEMO` 使用无胶囊背景的 `MetadataLabel`；自动保存、当前结果与旧结果使用 `InlineStatus`。
- 普通模型依据使用强调色；实测颜色为 `rgb(23, 107, 130)`。
- 独立作用假设使用警示色；实测颜色为 `rgb(147, 100, 22)`。
- 外部验证才映射为成功色；ANN 接受状态继续作为真实验证结果显示。
- 洋红色只用于荧光/响应曲线，选择态与主操作使用青色。

## 1280×720 审计

- `documentElement.clientWidth = 1280`，`documentElement.scrollWidth = 1280`，页面级水平溢出为 0。
- 建模顶部表面高 88 px，由 48 px 项目行与 40 px 运行行组成，严格保持两行。
- Run 按钮边界为 `x=1130..1248`，完整位于视口内。
- 三栏网络工作区宽 1037 px、高 531 px；对象索引和检查器可用，画布保留内部水平滚动。
- 结果 Dock 高 46 px，保持在工作台外边界内。
- 采集连续表面宽 1040 px；曲线区宽 758 px，控制区宽 280 px。内容可纵向滚动，页面没有水平滚动。
- `body` 基准字号为 14 px，未引入 8 px 或 9 px 的正文文本。

审计过程中未改动 BFN 计算、BLE、导入导出、历史、结果签名、Undo/Redo 或直接操作逻辑。
