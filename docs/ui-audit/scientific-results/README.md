# Scientific Results & Figure Workflow UI Audit

## 审计范围

本目录记录 Batch 4 科学结果工作流的实际桌面界面审计。审计于 2026-08-26 在 Vite 本地应用中完成，主截图视口为 1440×900；截图均由工作台实际状态生成并保存为 PNG。演示网络、参数和结果继续标记为 Demo / 未经实验验证。

图表光标显示求解器采样网格中的真实点，不做插值。参数区间是参数范围传播得到的输出包络，不是统计置信区间。ANN accepted 只表示当前 R² 与 NRMSE 达到近似质量门槛，不代表实验有效性。

## 运行对比契约

历史候选必须与当前结果同时满足以下四项：

1. networkId 相同；
2. mode 相同；
3. primaryInputSourceId 相同；
4. outputMonitorId 相同。

界面一次只允许选择一条历史运行。历史曲线使用自己的点网格和实际输出；缺少的模块参数、上下界或 ANN 近似保持空缺，不用当前运行数据补齐。无效时间显示“未知 / Unknown”，语言环境非法时使用稳定回退格式。

## 实际界面导出

| 文件                               | 核验结果                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------- |
| `exports/demo-static-response.svg` | 9902 bytes；白色背景；3 条 path、12 个 text；不含栅格 `<image>`。          |

| `exports/demo-static-data.csv`     | 6274 bytes；UTF-8 BOM；34 行（表头 + 33 个稳态采样点）；保留原始数值精度。 |

CSV 表头为：

```text
run_id,run_role,completed_at,mode,coordinate,time_hours,input:source-ahl,module:module-ahl-sensor,module:module-reporter,output,lower,upper,extrapolated
```

SVG 和 PNG 使用白色出版背景，不随当前浅色/深色主题改变。CSV 中 current / comparison 运行角色显式分开；本次归档文件只导出当前稳态演示运行。

## 1280×720 布局复核

- viewport 为 1280×720；document 和 body 的 clientWidth、scrollWidth 均为 1280 px，页面级水平溢出为 0；
- 分析工具栏中的撤销、重做、稳态、动态、设置输入和运行按钮均在视口内；
- X/Y 轴设置、导出菜单和历史对比下拉框可见且可操作；
- 结果面板宽 1037.48 px、高 302.40 px，底边与工作台表面底边只相差 0.67 px 的子像素舍入；
- 图表使用结果区内部空间，工作台和结果区各自管理溢出，不扩张文档宽度。

## 科学解释边界

- 参数区间是模型参数区间传播结果，不表述为置信区间；
- ANN 接受状态是近似误差门槛结论，不表述为实验验证；
- Demo 结果不用于构建成功率、实验效能、生物安全或法规结论；
- 历史对比用于复核兼容运行的数值差异，不自动推断因果关系或补造历史元数据。
