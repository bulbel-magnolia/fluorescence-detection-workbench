## 1280×720 边界检查

- `document.scrollWidth = document.clientWidth = 1280`，没有页面级水平溢出；
- 应用侧栏收缩为 190 px 图标导航；
- 项目工具栏和分析工具栏完整位于视口内；
- 工作区宽 1039 px，属性检查器宽 270 px，底部结果 Dock 高 46 px；
- 画布使用独立滚动区域浏览 980×520 工程空间，不挤压属性检查器；
- 正文与建模交互文字保持至少 10 px，核心正文为 12–14 px。

## 视觉边界

- 常规 Pane、Section 和 Row 不使用阴影；阴影只保留给浮动 Dialog、Drawer 和 Tooltip；
- 不使用霓虹、玻璃、辉光、扫描线、装饰渐变或悬浮抬升；
- 洋红色仅用于荧光信号和响应曲线，强调色用于选择与主操作，绿色用于兼容或成功；
- 本轮未改动 BFN-IR 结构、求解器、ANN、反向设计评分、持久化或 Undo/Redo 语义。
